# 关于数据

本应用使用以下数据。

- [公共交通开放数据中心](https://www.odpt.org/)
- [Mapbox](https://www.mapbox.com)
- [OpenStreetMap](https://www.openstreetmap.org)
- [Rain Viewer](https://www.rainviewer.com)
- [羽田机场飞行路线](https://www.ntrack.mlit.go.jp)

本应用中的公共交通数据来自公共交通开放数据中心，并以各公共交通运营商提供的数据为基础。数据的准确性和完整性不作保证。有关本应用内容的问题，请勿直接联系公共交通运营商。
