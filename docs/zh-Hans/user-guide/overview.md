# Mini Tokyo 3D 概览

<img :src="$withBase('/images/screenshot1.jpg')">

Mini Tokyo 3D 是一张呈现东京公共交通的实时 3D 地图。正在运行的列车以及正在起降的飞机，会以流畅的动画显示在逼真的 3D 地图上。它是现实世界在数字世界中的“数字孪生”。

用户可以在 3D 地图上自由移动，放大想查看的地点，了解东京的“此时此刻”。你可以把它当作线路图查询换乘路线，出门前查看目的地附近的街区和天气，也可以自动跟踪列车欣赏沿线风景，甚至根据末班车的当前位置判断自己是否该加快脚步。

Mini Tokyo 3D 是一款 Web 应用，只要有 Web 浏览器，无论使用 PC、智能手机、平板电脑还是机顶盒等设备，都可以通过以下网址访问。

[https://minitokyo3d.com](https://minitokyo3d.com)

Mini Tokyo 3D 具有以下特点。

## 全方位实时呈现

<img :src="$withBase('/images/day-night.jpg')" style="width: 640px;">

你可以从喜欢的视角观看依据实际时刻表和实时延误信息运行的列车与飞机。景色会随东京的日出和日落时间改变明暗，还能看到晚霞。此外，地图会依据实时天气信息显示降雨动画，带来更真实的观感。

## 清晰易读的铁路地图

<img :src="$withBase('/images/transit.jpg')" style="width: 328px;">

Mini Tokyo 3D 使用官方线路图和导向标识中的线路颜色，并根据地图缩放级别适当调整各条线路的间距，使线路清晰易读。名称不同但可以互相换乘的车站之间会显示连接关系，帮助乘客顺利换乘。列车采用简洁的纯色长方体造型，以增强其符号辨识度。

## 操作性与性能

<img :src="$withBase('/images/performance.jpg')" style="width: 537px;">

高峰时段会有超过 2,200 列列车同时运行。凭借优化的数据结构和处理逻辑，即使在智能手机上也能实现十分流畅的运行动画。从视角移动、地面与地下视图切换，到列车和飞机的淡入淡出，应用各处均使用每秒 60 帧的流畅动画。

## 多语言支持

<img :src="$withBase('/images/multilanguage.jpg')" style="width: 219px;">

除日语外，Mini Tokyo 3D 还支持访日游客常用的英语、法语、简体中文、繁体中文和韩语。不仅用户界面文本支持多语言，线路名、车站名、列车种别、机场名和航空公司名等也已实现多语言显示。用户界面文本还支持泰语、尼泊尔语、巴西葡萄牙语、西班牙语和德语。

## 地面与地下视图切换

<img :src="$withBase('/images/shinjuku-overground.jpg')" style="width: 300px;"> <img :src="$withBase('/images/shinjuku-underground.jpg')" style="width: 300px;">

东京的铁路网络是世界上最复杂的铁路网络之一。Mini Tokyo 3D 可以在地面和地下铁路网络之间切换，在提高地图可读性的同时，也能清晰呈现现实中看不见的地铁运行情况。

## 实用的实时路线搜索

<img :src="$withBase('/images/route-search.jpg')" style="width: 563px;">

Mini Tokyo 3D 提供独特的实时延误路线搜索功能。通过支持移动设备手势的直观操作，它会根据列车延误情况，在清晰易懂的 3D 地图上显示多个候选出行路线。
