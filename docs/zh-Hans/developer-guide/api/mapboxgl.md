# mapboxgl

`mapboxgl` 是包含 [Mapbox GL JS](https://docs.mapbox.com/mapbox-gl-js/api/) 库中所有类、对象和属性的对象，用作 Mapbox API 的命名空间。

**类型** [`Object`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Object)

## 属性

更多信息请参阅 [Mapbox API](https://docs.mapbox.com/mapbox-gl-js/api/)。

## 示例

```js
const lnglat = new mt3d.mapboxgl.LngLat(139.7143859, 35.6778094);
const marker = new mt3d.Marker().setLngLat(lnglat);
```
