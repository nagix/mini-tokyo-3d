# Map

Map 对象表示页面上的 Mini Tokyo 3D 地图。通过指定 container 和其他选项创建 Map 后，Mini Tokyo 3D 会在页面中初始化地图并返回 Map 对象。

扩展自 Evented (opens new window)。

new Map(options: Object)

# 参数

# options (Object (opens new window))

名称 说明
options.accessToken
string (opens new window)		 Mapbox (opens new window) 访问令牌。如果未指定，加载地图时会出错，因此请务必获取你的网站专用的访问令牌。
options.bearing
number (opens new window)
默认值： 0		 地图的初始方位角（旋转角度），从正北方向逆时针计算，单位为度。省略时默认为 0。
options.center
LngLatLike (opens new window)
默认值： [139.7670, 35.6814]		 地图的初始地理中心点。省略时默认为东京站附近（[139.7670, 35.6814]）。注意：为与 GeoJSON 一致，Mini Tokyo 3D 使用经度、纬度的坐标顺序。
options.clockControl
boolean (opens new window)
默认值： true		 为 true 时，在地图上添加日期和时间显示。
options.configControl
boolean (opens new window)
默认值： true		 为 true 时，在地图上添加设置按钮。
options.container
string (opens new window)		 Mini Tokyo 3D 用于渲染地图的 HTML 元素 id。指定的元素不能包含子元素。
options.dataSources
Array (opens new window)<DataSource>		 Mini Tokyo 3D 的列车、航班和巴士数据源数组。省略时使用内置的 ODPT 与 Mini Tokyo 3D 列车和航班数据源。提供此选项会替换内置数据源；如需保留它们，请明确将其包含在内，或在运行时通过 Map#addDataSource 添加自己的数据源。每个数据源都必须具有唯一的 id。
options.dataUrl
string (opens new window)		 Mini Tokyo 3D 数据网址。省略时使用 'https://minitokyo3d.com/data'。
options.ecoFrameRate
number (opens new window)
默认值： 1		 省电模式开启时列车和飞机动画的帧率（帧/秒）。可指定 1 至 60。值越低，动画越不流畅，但 CPU 资源占用也越低，从而减少移动设备耗电。省略时默认为 1。
options.ecoMode
string (opens new window)
默认值： 'normal'		 初始省电模式。支持 'normal' 和 'eco'。
options.fullscreenControl
boolean (opens new window)
默认值： true		 为 true 时，在地图上添加全屏按钮。
options.lang
string (opens new window)		 表示语言的 IETF 语言标签 (opens new window)。省略时使用浏览器默认语言。目前支持 'ja'、'en'、'ko'、'zh-Hans'、'zh-Hant'、'th'、'ne'、'pt-BR'、'fr'、'es' 和 'de'。指定不支持的语言时使用 'en'。
options.modeControl
boolean (opens new window)
默认值： true		 为 true 时，在地图上添加模式切换按钮。
options.navigationControl
boolean (opens new window)
默认值： true		 为 true 时，在地图上添加导航按钮。
options.pitch
number (opens new window)
默认值： 60		 地图的初始倾斜角，相对于屏幕平面计算，单位为度（0–85）。省略时默认为 60。
options.plugins
Array (opens new window)<PluginInterface>		 要添加的插件数组。每个插件都必须实现 PluginInterface。
options.searchControl
boolean (opens new window)
默认值： true		 为 true 时，在地图上添加搜索按钮。
options.secrets
Secrets		 用于存储获取数据时所用访问令牌的对象。
options.selection
string (opens new window)		 要跟踪的列车或航班 ID，或者要选择的车站 ID。列车 ID 格式为 'odpt.Train:<运营商 ID>.<线路 ID>.<列车编号>'；航班 ID 格式为 'odpt.FlightInformationArrival:<运营商 ID>.<机场 ID>.<航班号>' 或 'odpt.FlightInformationDeparture:<运营商 ID>.<机场 ID>.<航班号>'；车站 ID 格式为 'odpt.Station:<运营商 ID>.<线路 ID>.<车站 ID>'。可以省略 'odpt.*:' 部分。详细信息请参阅公共交通开放数据中心 API 规范 (opens new window)。
options.trackingMode
string (opens new window)
默认值： 'position'		 初始跟踪模式。支持 'position'、'back'、'topback'、'front'、'topfront'、'helicopter'、'drone' 和 'bird'。
options.zoom
number (opens new window)
默认值： 14		 地图的初始缩放级别。省略时默认为 14。

# 实例成员

# addDataSource(source)

# 参数

source (DataSource) 要添加的数据源。

# 返回值

Map：返回自身，以便进行方法链式调用。

# addLayer(layer)

向地图添加图层。

# 参数

layer (Object (opens new window) | CustomLayerInterface (opens new window) | GeoJsonLayerInterface | ThreeLayerInterface | Tile3DLayerInterface) 要添加的图层，须符合 Mapbox 样式规范的图层定义 (opens new window)、CustomLayerInterface (opens new window)、GeoJsonLayerInterface、ThreeLayerInterface 或 Tile3DLayerInterface 规范。

# 返回值

# easeTo(options)

通过动画过渡更改 center、zoom、bearing、pitch 和 padding 的任意组合。options 中未指定的设置会保留当前值。

注意：如果用户在操作系统中启用了“减少动态效果”辅助功能，过渡会立即完成，除非 options 包含 essential: true。

# 参数

options (Object (opens new window)) 描述过渡目标和动画的选项。接受 CameraOptions (opens new window) 和 AnimationOptions (opens new window)。

# 返回值

Map：返回自身，以便进行方法链式调用。

# flyTo(options)

更改 center、zoom、bearing 和 pitch 的任意组合，并沿模拟飞行的曲线执行动画过渡。动画会流畅地结合缩放和平移，即使跨越很远距离，也能帮助用户保持方向感。

如果用户在操作系统中启用了“减少动态效果”辅助功能，动画会被跳过，效果等同于 jumpTo，除非 options 包含 essential: true。

# 参数

options (Object (opens new window)) 描述过渡目标和动画的选项。接受 CameraOptions (opens new window)、AnimationOptions (opens new window) 及以下附加选项。

名称 说明
options.curve
number (opens new window)
默认值： 1.42		 沿飞行路径采用的缩放“曲线”。值越大，缩放越明显、动画越夸张；值越小，缩放越少、效果越接近 Map#easeTo。1.42 是 van Wijk（2003） (opens new window)所述用户研究参与者选择的平均值。Math.pow(6, 0.25) 等同于均方根平均速度，值为 1 时会产生圆周运动。指定 options.minZoom 后忽略此选项。
options.maxDuration
number (opens new window)		 动画的最长持续时间，单位为毫秒。如果持续时间超过最大值，则重置为 0。
options.minZoom
number (opens new window)		 飞行路径最高点处从 0 开始计算的缩放级别。指定此选项后忽略 options.curve。
options.screenSpeed
number (opens new window)		 假设采用线性时间曲线，以每秒移动多少个屏幕跨度表示的动画平均速度。指定 options.speed 后忽略此选项。
options.speed
number (opens new window)
默认值： 1.2		 相对于 options.curve 定义的动画平均速度。速度 1.2 表示地图每秒沿飞行路径移动 options.curve 的 1.2 倍屏幕跨度。一个屏幕跨度指地图的可见范围，不对应固定物理距离，会随缩放级别而变化。

# 返回值

Map：返回自身，以便进行方法链式调用。

# getBearing()

返回地图当前的方位角。方位角表示地图朝上的指南针方向；例如，方位角为 90° 时，地图东方朝上。

# 返回值

number (opens new window): 地图当前的方位角。

# getCenter()

返回地图的地理中心点。

# 返回值

LngLat (opens new window): 地图的地理中心点。

# getClockMode()

返回当前时钟模式。

# 返回值

string (opens new window): 表示当前时钟模式的字符串，为 'realtime' 或 'playback'。

# getEcoMode()

返回当前省电模式。

# 返回值

string (opens new window): 表示当前省电模式的字符串，为 'normal' 或 'eco'。

# getLight()

返回地图当前设置的光源。返回对象的结构与 light 事件的载荷相同。

# 返回值

Object (opens new window): 当前光源。对象属性请参阅 light 事件。

# getMapboxMap()

返回地图中使用的 Mapbox Map (opens new window) 对象。

# 返回值

Map (opens new window): Mapbox Map。

# getModelPosition(lnglat, altitude)

将 LngLat 投影为 MercatorCoordinate，并返回以地图初始中心（options.center）为原点平移后的墨卡托坐标。

# 参数

lnglat (LngLatLike (opens new window)) 要投影的位置。

altitude (number (opens new window)) 位置的海拔高度，单位为米。

# 返回值

{x: number (opens new window), y: number (opens new window), z: number (opens new window)}: 以地图初始中心（options.center）为原点平移后的墨卡托坐标。

# getModelScale()

返回从以米为单位的现实世界坐标转换到 MercatorCoordinate 的比例。该值表示地图初始中心（options.center）位置的 1 米对应多少 MercatorCoordinate 单位。

# 返回值

number (opens new window): 从以米为单位的现实世界坐标转换到 MercatorCoordinate 的比例。

# getPitch()

返回地图当前的倾斜角。

# 返回值

number (opens new window): 地图当前的倾斜角，相对于屏幕平面计算，单位为度。

# getSelection()

返回正在跟踪的列车或航班 ID，或者已选车站的 ID 数组。

# 返回值

string (opens new window) | Array (opens new window)<string (opens new window)>: 正在跟踪的列车或航班 ID，或者已选车站的 ID 数组。列车 ID 格式为 '<运营商 ID>.<线路 ID>.<列车编号>'；航班 ID 格式为 '<运营商 ID>.<机场 ID>.<航班号>'；车站 ID 格式为 '<运营商 ID>.<线路 ID>.<车站 ID>'。

# getTrackingMode()

返回当前跟踪模式。各跟踪模式的详细信息请参阅跟踪模式设置。

# 返回值

string (opens new window): 表示当前跟踪模式的字符串，为 'position'、'back'、'topback'、'front'、'topfront'、'helicopter'、'drone' 或 'bird'。

注意

跟踪模式 'heading' 已弃用，并会回退到 'topback'。

# getViewMode()

返回当前视图模式。

# 返回值

string (opens new window): 表示当前视图模式的字符串，为 'ground' 或 'underground'。

# getZoom()

返回地图当前的缩放级别。

# 返回值

number (opens new window): 地图当前的缩放级别。

# hasDarkBackground()

检查地图背景颜色是否为深色。

# 返回值

boolean (opens new window): 地图背景颜色为深色时是 true，否则是 false。

# jumpTo(options)

不使用动画过渡，更改 center、zoom、bearing 和 pitch 的任意组合。options 中未指定的设置会保留当前值。

# 参数

options (CameraOptions (opens new window)) 选项对象。

# 返回值

Map：返回自身，以便进行方法链式调用。

# 参数

listener (Function (opens new window)) 此前作为监听器安装的函数。

# 返回值

Map：返回自身，以便进行方法链式调用。

# on(type, listener)

添加指定类型事件的监听器。

# 参数

type (string (opens new window)) 要监听的事件类型。

listener (Function (opens new window)) 事件触发时调用的函数。

# 返回值

Map：返回自身，以便进行方法链式调用。

# once(type, listener)

为指定事件类型添加只调用一次的监听器。

# 参数

type (string (opens new window)) 要添加监听器的事件类型。

listener (Function (opens new window)) 事件触发时调用的函数。

# 返回值

Map：返回自身，以便进行方法链式调用。

# removeDataSource(id)

从地图中移除具有指定 ID 的数据源。

# 参数

id (string (opens new window)) 要移除的数据源 ID。

# 返回值

Map：返回自身，以便进行方法链式调用。

# removeLayer(id)

从地图中移除具有指定 ID 的图层。

如果不存在该图层，则触发 error 事件。

# 参数

id (string (opens new window)) 要移除的图层 ID。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setBearing(bearing)

设置地图的方位角（旋转角度）。方位角表示地图朝上的指南针方向；例如，方位角为 90° 时，地图东方朝上。

等同于 jumpTo({bearing: bearing})。

# 参数

bearing (number (opens new window)) 要设置的方位角。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setCenter(center)

设置地图的地理中心点。等同于 jumpTo({center: center})。

# 参数

center (LngLatLike (opens new window)) 要设置的中心点。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setClockMode(mode)

设置时钟模式。实时模式（'realtime'）下，地图按照当前实际运行情况显示列车和飞机；播放模式（'playback'）下，可以指定时间和时间流逝速度。

# 参数

mode (string (opens new window)) 表示时钟模式的字符串，为 'realtime' 或 'playback'。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setEcoMode(mode)

设置省电模式。普通模式（'normal'）下，列车和飞机动画帧率设为 60；省电模式（'eco'）下，帧率设为 Map 构造函数选项 ecoFrameRate。

# 参数

mode (string (opens new window)) 表示省电模式的字符串，为 'normal' 或 'eco'。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setLayerVisibility(layerId, visibility)

设置图层可见性。指定 'visible' 使图层可见，指定 'none' 使图层不可见。

# 参数

layerId (string (opens new window)) 要设置可见性的图层 ID。

visibility (string (opens new window)) 图层是否显示，为 'visible' 或 'none'。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setPitch(pitch)

设置地图的倾斜角。等同于 jumpTo({pitch: pitch})。

# 参数

pitch (number (opens new window)) 要设置的倾斜角，相对于屏幕平面计算，单位为度（0–85）。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setSelection(id)

设置要跟踪的列车或航班 ID，或者要选择的车站 ID。列车 ID 格式为 'odpt.Train:<运营商 ID>.<线路 ID>.<列车编号>'；航班 ID 格式为 'odpt.FlightInformationArrival:<运营商 ID>.<机场 ID>.<航班号>' 或 'odpt.FlightInformationDeparture:<运营商 ID>.<机场 ID>.<航班号>'；车站 ID 格式为 'odpt.Station:<运营商 ID>.<线路 ID>.<车站 ID>'。可以省略 'odpt.*:' 部分。详细信息请参阅公共交通开放数据中心 API 规范 (opens new window)。

# 参数

id (string (opens new window)) 要跟踪的列车或航班 ID，或者要选择的车站 ID。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setTrackingMode(mode)

设置跟踪模式。各跟踪模式的详细信息请参阅跟踪模式设置。

# 参数

mode (string (opens new window)) 表示跟踪模式的字符串，为 'position'、'back'、'topback'、'front'、'topfront'、'helicopter'、'drone' 或 'bird'。

注意

跟踪模式 'heading' 已弃用，并会回退到 'topback'。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setViewMode(mode)

设置视图模式。地面模式（'ground'）下，地面线路、车站、列车和飞机明亮显示，地下线路、车站和列车半透明显示；地下模式（'underground'）下，地图变暗，地面线路、车站、列车和飞机半透明显示，地下线路、车站和列车明亮显示。

# 参数

mode (string (opens new window)) 表示视图模式的字符串，为 'ground' 或 'underground'。

# 返回值

Map：返回自身，以便进行方法链式调用。

# setZoom(zoom)

设置地图的缩放级别。等同于 jumpTo({zoom: zoom})。

# 参数

zoom (number (opens new window)) 要设置的缩放级别（0–22）。

# 返回值

Map：返回自身，以便进行方法链式调用。

# 事件

# boxzoomcancel

当用户取消“框选缩放”交互，或边界框未达到最小尺寸阈值时触发。参阅 BoxZoomHandler (opens new window)。

类型 MapBoxZoomEvent (opens new window)

# boxzoomend

当“框选缩放”交互结束时触发。参阅 BoxZoomHandler (opens new window)。

类型 MapBoxZoomEvent (opens new window)

# boxzoomstart

当“框选缩放”交互开始时触发。参阅 BoxZoomHandler (opens new window)。

类型 MapBoxZoomEvent (opens new window)

# click

当指针设备（通常是鼠标）在地图同一点按下并释放时触发。

类型 MapMouseEvent (opens new window)

# clockmode

当时钟模式改变时触发。

类型 Object (opens new window)

# 属性

mode (string (opens new window)): 表示时钟模式的字符串，为 'realtime' 或 'playback'。

# contextmenu

当在地图内单击鼠标右键或按下上下文菜单键时触发。

类型 MapMouseEvent (opens new window)

# dblclick

当指针设备（通常是鼠标）在地图同一点快速按下并释放两次时触发。

类型 MapMouseEvent (opens new window)

# deselection

当取消跟踪列车或飞机，或取消选择车站时触发。

类型 Object (opens new window)

# 属性

deselection (string (opens new window) | Array (opens new window)<string (opens new window)>): 取消跟踪的列车或航班 ID，或者取消选择的车站 ID 数组。列车 ID 格式为 '<运营商 ID>.<线路 ID>.<列车编号>'；航班 ID 格式为 '<运营商 ID>.<机场 ID>.<航班号>'；车站 ID 格式为 '<运营商 ID>.<线路 ID>.<车站 ID>'。

# drag

在“拖动平移”交互期间反复触发。参阅 DragPanHandler (opens new window)。

类型 (MapMouseEvent (opens new window) | MapTouchEvent (opens new window))

# dragend

当“拖动平移”交互结束时触发。参阅 DragPanHandler (opens new window)。

类型 (MapMouseEvent (opens new window) | MapTouchEvent (opens new window))

# dragstart

当“拖动平移”交互开始时触发。参阅 DragPanHandler (opens new window)。

类型 (MapMouseEvent (opens new window) | MapTouchEvent (opens new window))

# ecomode

当省电模式改变时触发。

类型 Object (opens new window)

# 属性

mode (string (opens new window)): 表示省电模式的字符串，为 'normal' 或 'eco'。

# error

发生错误时触发。这是 Mini Tokyo 3D 的主要错误报告机制。为更好地支持异步操作，这里使用事件而不是 throw。如果 error 事件未绑定监听器，错误会输出到控制台。

类型 Object (opens new window)

# 属性

message (string (opens new window)): 错误消息。

# light

地图上设置的光源发生变化时触发，例如一天中的时间或视图模式改变时。该事件可用于使自定义图层或插件与地图光照保持同步。

类型 Object (opens new window)

# 属性

directional (Object (opens new window)): 平行光。

名称 说明
directional.color
