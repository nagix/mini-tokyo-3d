# 设置

# 图层显示设置

单击或轻触图层图标按钮，可打开“图层显示设置”面板。在面板中，可以开启或关闭叠加在地图上的图层。引入相应插件后，列表中会显示降水、烟花、实时摄像头、PLATEAU、GTFS 和东京 2020 奥运会图层。单击或轻触面板右上角的“×”按钮或面板外区域，可关闭面板。

单击或轻触各图层图标，可以切换图层的显示状态（开启时图标外框呈浅蓝色）。有关各图层功能的更多信息，请参阅插件。

# 跟踪模式设置

单击或轻触相机图标按钮，可打开“跟踪模式设置”面板。在该面板中，可以切换跟踪列车或飞机时使用的视角。单击或轻触面板右上角的“×”按钮或面板外区域，可关闭面板。

# 仅位置

在不改变当前距离、方向和俯角的情况下跟踪目标列车或飞机。使用此视角时，可以通过导航按钮或键盘控制缩放、旋转和倾斜地图。

# 后方

从目标列车或飞机的后方沿行进方向进行跟踪。

# 后方的天空

从目标列车或飞机的斜后上方进行跟踪，并使其行进方向朝向屏幕上方。

# 前方

从目标列车或飞机的前方迎面进行跟踪。

# 前方的天空

从目标列车或飞机的斜前上方进行跟踪，并使其行进方向朝向屏幕下方。

# 直升机

以空中视角围绕目标列车或飞机旋转 360 度。

# 无人机

以较低高度和较近距离围绕目标列车或飞机旋转 360 度。

# 鸟

跟踪目标列车或飞机，并平滑、动态地改变距离、方向和俯角。

# 查看应用信息

单击或轻触信息图标按钮，可查看应用和数据信息，其中还会显示静态数据和动态数据的最后更新时间。单击或轻触面板右上角的“×”按钮或面板外区域，可关闭面板。
