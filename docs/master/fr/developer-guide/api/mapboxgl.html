# mapboxgl

mapboxgl est l'objet avec toutes les classes, objets et propriétés inclus dans Mapbox API (opens new window). Il est utilisé comme espace de noms pour l'API Mapbox.

Type Object (opens new window)

# Propriétés

Pour plus d’informations, consultez Mapbox API (opens new window).

# Exemple

const lnglat = new mt3d.mapboxgl.LngLat(139.7143859, 35.6778094);
const marker = new mt3d.Marker().setLngLat(lnglat);
