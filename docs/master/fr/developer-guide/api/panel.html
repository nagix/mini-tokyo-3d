# Panel

Crée un composant de panneau.

Hérite de Object (opens new window).

new Panel(options: Object)

# Paramètres

# options (Object (opens new window))

Nom Description
options.modal
boolean (opens new window)		 Si true, le panneau sera modal et se fermera si l'utilisateur clique à l'extérieur.

# Membres de l'instance

# addTo(map)

Ajoute le panneau à une carte.

# Paramètres

map (Map) La carte Mini Tokyo 3D à laquelle ajouter le panneau.

# Retours

Panel : se renvoie lui-même pour permettre le chaînage de méthodes.

# isOpen()

Vérifie si un panneau est ouvert.

# Retours

boolean (opens new window) : true si le panneau est ouvert, false s'il est fermé.

# remove()

Supprime le panneau d'une carte.

# Retours

Panel : se renvoie lui-même pour permettre le chaînage de méthodes.

# setButtons(buttons)

Définit les boutons sur le titre du panneau.

# Paramètres

buttons (Array (opens new window)<HTMLElement (opens new window)>) Un tableau d'éléments DOM à utiliser comme boutons sur le titre du panneau.

# Retours

Panel : se renvoie lui-même pour permettre le chaînage de méthodes.

# setHTML(html)

Définit le contenu du panneau sur le code HTML fourni sous forme de chaîne.

Cette méthode n'effectue pas de filtrage ou de nettoyage HTML et doit être utilisée uniquement avec du contenu fiable.

# Paramètres

html (string (opens new window)) Une chaîne représentant le contenu HTML du panneau.

# Retours

Panel : se renvoie lui-même pour permettre le chaînage de méthodes.

# setTitle(title)

Définit le titre du panneau sur une chaîne de texte.

# Paramètres

title (string (opens new window)) Le titre du panneau.

# Retours

Panel : se renvoie lui-même pour permettre le chaînage de méthodes.
